# 음악 출처

이 폴더의 곡은 모두 **탑노트(몬타나 주식회사)가 직접 가진 자체 음원**이다. 외부 음원·상업 음악은 쓰지 않는다.

| 파일 | 곡 | 원본 |
| --- | --- | --- |
| late-night-texts.mp3 | Late Night Texts | 탑노트 자체 음원 (Late Night Texts.wav) |
| borrowed-room.mp3 | Borrowed Room | 탑노트 자체 음원 (Borrowed Room.wav) |
| last-message-first.mp3 | Last Message First | 탑노트 자체 음원 (Last Message First.wav) |
| fox-satin.mp3 | Fox Satin | 탑노트 자체 음원 (Fox Satin.wav) |
| one-more-ping.mp3 | One More Ping | 탑노트 자체 음원 (One More Ping.wav) |
| talking-with-my-ex.mp3 | Talking With My Ex | 탑노트 자체 음원 (Talking With My Ex.wav) |
| fox-in-satin-x-one-more-ping.mp3 | Fox in Satin x One More Ping (Mashup) | 탑노트 자체 음원 (Fox in Satin x One More Ping (Mashup) (1).wav) |

- 192kbps mp3로 바꿔 둠. 카드뉴스 릴스(`scripts/card-reel.mjs`)가 게시물 번호 순서로 돌려 쓴다.
- `tracks.json`의 `start`(초)부터 쓴다: 곡 음량 곡선에서 조용한 구간 뒤 다시 꽉 차는 지점을 고름.
- `video/music.wav`(12.3초)는 예비용.
