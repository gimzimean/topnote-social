개인정보처리방침

시행일 2026년 10월 30일

1. 무엇을 하는 서비스인가요

탑노트 소셜은 운영자 본인의 인스타그램·틱톡 계정에 직접 만든 카드 이미지를 예약해 올리는 내부 도구입니다. 다른 사람의 계정에 연결하거나 다른 사람의 정보를 모으지 않습니다.

2. 처리하는 정보

운영자 본인 계정의 접근 토큰과 계정 식별자(아이디, 사용자 번호)만 처리합니다. 토큰은 암호화해 보관하며 게시물을 올리는 데만 씁니다.

3. 보관과 삭제

토큰은 연결을 끊거나 운영을 끝내면 바로 지웁니다. 인스타그램·틱톡 설정에서 앱 연결을 해제하면 토큰은 더 쓸 수 없습니다.

4. 제3자 제공

정보를 다른 곳에 팔거나 넘기지 않습니다. 게시물을 올리기 위해 Meta(인스타그램)와 TikTok의 공식 API로만 보냅니다.
